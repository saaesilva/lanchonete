> Aplicação web rápida e responsiva de cardápio digital para hamburguerias, lanchonetes e delivery. Permite seleção de produtos, controle dinâmico de carrinho e fechamento de pedidos direto no WhatsApp do estabelecimento.

---

## ✨ Funcionalidades

- 📱 **Interface 100% Responsiva**: Otimizada para celulares, tablets e desktops.
- 🍔 **Catálogo de Produtos**: Exibição organizada com fotos em alta qualidade, nomes, descrições e preços.
- 🛒 **Carrinho Dinâmico**:
  - Adição e remoção de itens em tempo real.
  - Contador flutuante com a quantidade total de itens selecionados.
  - Cálculo automático do valor total do pedido.
- 📍 **Validação de Endereço**: Campo obrigatório com feedback visual caso o usuário esqueça de preencher.
- 💬 **Checkout Direto via WhatsApp**: Gera automaticamente a mensagem estruturada com os itens do pedido, total e endereço de entrega pronto para envio.
- ⏰ **Status de Funcionamento em Tempo Real**: Indicador de "Aberto" ou "Fechado" baseado no horário atual.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico**
- **JavaScript Moderno (ES6+)** para manipulação do DOM e lógica do carrinho
- **Tailwind CSS** para estilização utilitária e design limpo
- **Font Awesome / Toastify** para ícones e notificações elegantes

---

## 🚀 Como Executar

Por ser uma aplicação estática (Vanilla JS + HTML), não requer servidor de compilação:

1. Clone o repositório:
   ```bash
   git clone https://github.com/saaesilva/lanchonete.git
   cd lanchonete
   ```
2. Abra o arquivo `index.html` diretamente em seu navegador ou utilize a extensão **Live Server** no VS Code.
